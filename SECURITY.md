# Security

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues or discussions.

Use GitHub's private vulnerability reporting or a repository security advisory when that capability is enabled. Include the affected component, reproduction steps, impact, and any relevant logs or patches.

Do not include secrets, API keys, credentials, or personal data in a report.

## Supported code

Security fixes should preserve the repository's existing automated validation and should not weaken meaningful checks merely to obtain a passing build.
